# Prompt cho model tiếp theo — U2.6d minimap/fog presentation + destination picker

Làm một package cỡ vừa cho U2.6d: dựng presentation read-only trên `ChunkDiscoveryState.create_view_snapshot()` — minimap/fog renderer vẽ discovered/active/current tiles và destination picker liệt kê discovered chunks qua `FastTravelDestinationCatalog`. UI chỉ phát intent (destination ID đã chọn) và render snapshot; không trừ cost, không teleport, không mutate domain trực tiếp — mọi mutation đi qua `Main.try_fast_travel()` đã có. Tôn trọng accessibility: UI scale, keyboard/gamepad navigation, giảm flash/motion, phân biệt trạng thái không chỉ bằng màu. Không đổi policy/cost/guard/cooldown của U2.6c và chưa autosave. Regression headless phủ snapshot rendering mapping (tile flag → cell), picker chỉ liệt kê discovered, intent invalid không gọi travel, và Main integration (chọn → travel thành công → minimap cập nhật current). Chạy focused checks rồi một full gate cuối + strict scan; cập nhật ui/module/gameplay/roadmap/checkpoint.
