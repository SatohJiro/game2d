# Prompt cho model tiếp theo — U1.12u world resource depletion

Tiếp tục bằng đúng một package U1.12u: audit identity/lifecycle hiện tại của world resource nodes rồi thêm typed persistence cho riêng trạng thái depletion của một resource subtype nhỏ nhất đã reachable. Không dùng localized text, node type enum, Node hoặc scene/asset path làm identity. Chứng minh round-trip, dữ liệu ngoài miền fail trước mutation, load không phát harvest/drop side effect; chạy full gate + leak-aware log scan và cập nhật contract/checkpoint docs. Nếu world instance chưa có stable identity, chỉ xây contract/adapter tối thiểu cho subtype đó, không mở rộng sang chunk streaming.
