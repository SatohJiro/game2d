# Prompt cho model tiếp theo — U2.6c fast-travel domain boundary

Làm một package cỡ vừa cho U2.6c: tạo typed fast-travel request/result/policy dựa trên `ChunkDiscoveryState`, stable destination ID/catalog và explicit cost/cooldown rule. Chỉ destination đã discover mới hợp lệ; current destination, stale discovery revision, unknown ID, thiếu cost hoặc combat/raid guard phải fail trước mutation. Nối Main qua command adapter atomic: resolve trước, trừ cost qua inventory transaction rồi cập nhật player/chunk admission; nếu admission thất bại phải không mất cost và không partial teleport. Không làm UI/minimap art, không dùng scene path/localized text làm identity và chưa autosave. Regression headless phủ positive/negative destination, undiscovered/stale/duplicate intent, cost conservation, encounter guard, exact scene/navigation/spawn ownership sau teleport và Save discovery compatibility. Chạy focused checks rồi một full gate cuối + strict scan; cập nhật data/world/module/gameplay/roadmap/checkpoint.
