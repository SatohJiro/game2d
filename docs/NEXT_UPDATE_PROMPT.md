# Prompt cho model tiếp theo — U2.8 authored biome tables

Làm một package cỡ vừa cho U2.8: thay species list cứng trong `AmbientSpawnPolicy.SPECIES` bằng authored biome table typed — mỗi biome ID ánh xạ tới bảng spawn gồm species pool có trọng số, level range và slot budget riêng, định danh bằng stable content ID (`biome.<id>` / `spawn_table.<biome>`). Table là data thuần (không logic), policy resolve giữ deterministic theo seed/time bucket/chunk/slot như cũ; biome không tồn tại → fallback `WorldChunkCatalog.DEFAULT_BIOME_ID` và log warning, không crash. Không đổi slot identity/cooldown/save schema. Regression headless phủ table lookup, weighted pick deterministic theo seed, fallback biome lạ, và Main integration (spawn theo biome của chunk thật). Chạy focused checks rồi một full gate cuối + strict scan; cập nhật world/module/gameplay/roadmap/checkpoint.
