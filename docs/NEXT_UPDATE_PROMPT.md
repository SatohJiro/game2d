# Prompt cho model tiếp theo — U1.12d base/quest persistence contract

Tiếp tục bằng đúng một package U1.12d: audit và định nghĩa typed stable identity/state cho base progression cùng quest progress để chặn reset và nhận reward lặp khi load. Không dùng quest title, localized text hoặc array index làm save identity; giữ reward/economy hiện tại và không mở rộng sang building placement/crop/world delta. Ưu tiên contract + deterministic snapshot/apply regression trước wiring autosave/UI, ghi rõ Save v1 compatibility vì chưa phát hành, chạy full gate + leak-aware log scan và cập nhật module/feature/checkpoint docs.
