# Prompt cho model tiếp theo — U2.2 chunk admission foundation

Làm một package cỡ vừa cho U2.2: pure admission policy tính tập 3×3 quanh player từ `ChunkCoordinate`, coordinator giữ active chunk records và phát deterministic admit/unload delta, cùng debug snapshot read-only trong Main. Dùng scene placeholder tự chứa hoặc record-only adapter; không di chuyển content world tĩnh, không spawn creature, không navigation và chưa đổi Save v1. Regression phải phủ crossing biên dương/âm, no-op trong cùng chunk, thứ tự key ổn định, admit-before-unload hoặc policy được ghi rõ, duplicate/stale request guard. Chạy focused checks rồi một full gate cuối + strict scan, cập nhật contract/module/roadmap/checkpoint.
